# RoNix - Automated Susu & Micro-Savings Platform

RoNix is a financial technology solution designed to modernize traditional group and individual micro-savings (Susu) practices across West Africa.

## Project Structure
- docs/: Deliverables (D0 to D10) covering SRS, Architecture, Testing, and Operations.
- mobile/: React Native (Expo Router) client application.
- supabase/: Database DDL migrations, RLS security policies, and Serverless Edge Functions.
